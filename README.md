# BLAZE Live Lane Picker

Built by Joe Haigh for BLAZE Live, David Lloyd Hatfield.

A single-page tool for allocating studio stations (Cardio, Strength, Combat) at BLAZE Live:
paste or upload the class register, pre-allocate requested stations, then randomise the rest
or pick a lane for each person as they arrive. Everything typed in is stored only in the
browser on the device in use. No member data is kept in this repository.
